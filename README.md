# 🍽️ Find Meals For Your Ingredients

A simple and interactive web application that allows users to search for meals based on the ingredients they have. It fetches meal data using **TheMealDB API** and displays recipes with instructions, meal images, and a link to a YouTube tutorial.

---

## 🚀 Features

- Search meals by entering ingredient name  
- Displays a list of meals with images and names  
- View full recipe details in a modal popup  
- Watch YouTube video tutorials for meals  
- Fully responsive UI  
- Clean and easy-to-understand code structure  

---

## 🛠️ Technologies Used

| Technology | Usage |
|-----------|--------|
| **HTML5** | Page structure |
| **CSS3** | Styling and layout |
| **JavaScript (Vanilla JS)** | API calls, DOM manipulation |
| **TheMealDB API** | Meal and Recipe data |
| **Google Fonts / Font Awesome** | UI enhancements |

---

🔍 How It Works

Type an ingredient in the search box

Click the Search button

The app sends a request to TheMealDB API

Matching meals are displayed

Click Get Recipe to view full details
